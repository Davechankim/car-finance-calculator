## 2. v2 문서 대비 발견·정정 사항

1. **테스트 케이스 A 기대값 오류**: v2 문서는 "≈939,929원"이라 했으나 정확값은 **939,401.5원**.
   검산: (1.005)⁴⁸=1.2704896 → 연금현가계수 42.580316 → 40,000,000÷42.580316 = 939,401.5.
   v2 코드가 이 값을 만들었다면 월납이 약 528원 과대계상된 것 (원인 추정: 오타 또는 다른 금리 사용).
2. **테스트 케이스 D는 실무형 규칙으로 갱신**: 단순 "1,500만 제한"이 아니라
   업무사용비율(15/18) 적용 후 감가상당액 800만 한도 초과분(250만)을 추가 차감 → 인정 1,250만.
3. **보상판매 처리 변경**: v2는 금융 원금에서 차감 → v3는 현금 차감 (다대수·자유 빌더와 일관).
   월납이 보상판매에 영향받지 않게 됨. 차이는 이자 상당분 (면책 명시).
4. **신규 반영**: 금융리스 표준 모델 · 부가세 환급 · 취득세 · 차량 분류 · 운행기록부 · 800만 감가 한도.
5. **운용리스 만기 승계 문구 정정**: 스펙 매트릭스의 "반납/인수/승계 중 최저"를 "반납/인수 중 최저 (승계는 중도만)"로 — 만기 시 승계는 실무상 무의미.
6. **2026 리뷰 정정**: ①운용리스 조기인수에 남은 원금이 빠지던 오류 수정
   ②부동산임대업 50% 휴리스틱 폐지 및 법정 특례 한도 분리
   ③계약별 최적시점 대신 공통 목표 보유기간 비교로 오판 가능성 제거
   ④잔존가치의 기간 이자와 실제 월납 기반 잔액 반영
   ⑤취득세 과표의 VAT 제외, 환급 VAT의 감가·비용 이중 반영 제거, 취득세 자본화
   ⑥렌트·운용리스는 계약 만기에서 고정하되 금융리스·할부는 금융 만기 후 월납만
   중단하고 실제 보유기간의 보험·자동차세·정비·감가·세금·시세를 계속 계산
   ⑦실제 월납을 금융·보험·자동차세·정비·서비스로 분리해 잔여채무·이자·VAT의
   과도한 감소·환급을 방지하고, 운용리스 정비비 구분 시 실제액·미구분 시
   보험·자동차세 차감액의 7% 대체 규칙을 적용
   ⑧계산 세율·한도를 승인 스냅샷 하나에서 읽도록 연결
   ⑨VAT 과세유형·증빙과 한도 제외/VAT 적격 차종 규칙을 분리하고 연 정비비 VAT 반영
   ⑩보유기간 전체 연간비용과 금융 종료 후 추가비용 분리
   ⑪과도한 할부 월납의 조기완납 상한과 운용리스 서비스비 감가상당액 반영
   ⑫소규모 부동산임대 법인 비용한도 선택과 2026 소규모법인 세율 판정을 분리
   ⑬계산 시작일~승인 종료일의 세금혜택 상한, 기간 밖 납부세금 보수 유지 및 저장 envelope 규칙 ID 검증
   ⑭개인 간이과세 매각 VAT 업종별 최대율 산식, 법인 선택 차단과 겸영·불확실 과소계상 방지 보수값 반영.

  취득세 과표에서 부가가치세를 제외하는 규정을 대조했다:
  [지방세법 제12조](https://www.law.go.kr/LSW/lbook/lbFileDownload.do?flExt=pdf&lbookConflSeq=68006&lbookSeq=73655),
  [지방세특례제한법 제67조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1018270819),
  [지방세법 시행령 제18조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0018&lsiSeq=286395&urlMode=lsScJoRltInfoR).
- 한도 제외 차량도 실제 업무 관련 비용만 인정한다는 원칙을 보수적으로 반영해,
  업무사용비율을 입력한 경우에는 해당 비율을 적용하고 미입력 시 100% 업무사용
  가정을 화면과 문서에 명시했다:

  [부가가치세법 제39조](https://law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1032170071).

  [부가가치세법 시행령 제111조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0111&lsiSeq=283641&urlMode=lsScJoRltInfoR).

6. 매입 VAT는 과세유형·적격증빙·차종으로, 매각 VAT는 과세유형과
   과세사업용 자산 여부로 별도 판정
   (개인 간이과세는 선택한 넓은 업종의 법정 최대율 추정,
   겸영·불확실은 일반세율 보수 적용;
   실제 안분·매입공제·공제세액과 포괄적 사업양도 자동판정은 미반영)

   (부분 가입일수·개인사업자 1대 예외 미반영)
8. 시세는 단순 감가커브 (모델·주행거리 미반영) — 시점별 직접입력으로 보완 가능

   과세분으로 가정해 적용하므로 실제 세금계산서 구성 확인 필요
10. 월납 구성표를 알 수 없어 총액을 금융·차량대금으로 입력하면 잔여채무와
    조기정산금에 오차가 생길 수 있음
11. 차량 매각손익에 대한 소득세·법인세 효과는 미반영
12. 한도 제외 차량은 업무사용비율 미입력 시 100% 업무사용으로 가정
13. 2026 승인기간 뒤 동일 세법 혜택 적용은 사용자가 선택하는 명시적
    시나리오이며 실제 개정사항을 자동 반영하지 않음. 납부세금은 0원 절벽을
    막기 위해 2026 규칙을 보수 유지하므로 실제 개정 시 차이가 날 수 있음
