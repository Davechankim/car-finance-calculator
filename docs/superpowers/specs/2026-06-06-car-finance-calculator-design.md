## 1. 목표

장기렌트·운용리스·금융리스·할부 4가지 자동차 조달 방식을 **자유 조합으로 비교**하는 웹 계산기.
v2(고정 3방식 비교)의 계산 골격을 계승하되, 다음을 새로 지원한다:

- **자유 비교 빌더**: 비교 항목을 원하는 만큼 추가 (예: 금융리스 그랜저 1대 vs 운용리스 카니발 3대 vs 장기렌트 카니발 3대)
- **금융리스** 방식 추가 (표준 모델: 만기 잔존가 지급 후 소유권 이전)
- **다중 차량(대수)** 지원 — 대당 세금 한도 정확 적용
- **실무형 세금 규칙**: 차량 분류, 운행기록부, 감가상각비(상당액) 800만 한도, 부가세 환급, 취득세
- 계산 엔진 분리 + 단위 테스트로 **검증 자동화** (v2 문서 6장 테스트 케이스 계승)

산출물: Next.js 앱 (Vercel 배포), 계산 검증 보고서.

## 4. 방식별 계산 규칙

### 4.1 공통 수학 (pmt.ts)

```
월이율 r = 연금리/100/12,  n = months,  yrs = m/12

PMT(p, r, n)        = r==0 ? p/n : p·r·(1+r)^n / ((1+r)^n − 1)
PMT_balloon(p,b)    = PMT(max(p − b/(1+r)^n, 0), r, n)
remBal(p, r, n, m)  = r==0 ? max(p − (p/n)·m, 0)
                           : max(p·(1+r)^m − PMT·((1+r)^m − 1)/r, 0)
실제월납 잔액(m)    = max(p·(1+r)^m − 실제월납·((1+r)^m−1)/r, 잔존 현재가치)
```

### 4.2 방식 매트릭스 (1대당, costAt.ts)

| | 장기렌트 (rent) | 운용리스 (oplease) | 금융리스 (finlease) | 할부 (installment) |
|---|---|---|---|---|
| 최초 금융잔액 p | P−선납−지원 | P−선납−지원 | P−선납−지원 | min(대출금, P−선납−지원) |
| 초기 현금 | 선납+보증금+기타비용 | 선납+보증금+기타비용 | 선납+보증금+기타비용+**취득세** | 선납+현금추가¹+기타비용+**취득세** |
| 취득세 | — (렌트사 부담) | 인수금액의 공급가액 × 세율 | P의 공급가액 × 세율 | P의 공급가액 × 세율 |
| 부가세 환급² | 월납×10/110 매월 | **없음** (리스료 면세) | P×10/110 초기 1회 | P×10/110 초기 1회 |
| 만기 처리 | 반납 | 반납/인수 중 최저 (승계는 중도만) | 잔존 지급 → 소유 (−시세) | 소유 (−시세) |
| 중도 출구 | min(해지, 승계) | min(해지반납, 승계, 인수후매각) | min(승계, 조기정산후매각) | 중도상환 후 매각 |
| 비용처리 | 렌트료 (한도 내) | 리스료 (한도 내) | 감가상각 + 이자 | 감가상각 + 이자 |
| 감가상각비 상당액³ | 렌트료 × 70% | 리스료 × 93% | P/5 (5년 정액) | P/5 (5년 정액) |

¹ 현금추가 = max(P − 선납 − 지원 − 대출, 0)
² 환급 조건: `biz ≠ none`(일반과세 가정) **AND** `category = exempt`. 일반 승용차는 매입세액공제 불가. 렌트의 매월 환급은 **렌트료에 대해서만** 적용 (보험·정비는 제외).
³ 법인세법 시행규칙 근사: 렌트료의 70%, 리스료는 보험·자동차세·정비 차감분(≈93%). finlease/installment는 실제 감가상각비.

보상판매(tradeIn)는 금융 원금에 넣지 않고 **항목 합산 단계에서 현금 1회 차감**한다(아래 4.3). 월납입금이 보상판매 금액에 영향받지 않으며, v2(원금 차감)와의 차이는 이자 상당분으로 §8 한계에 명시.

### 4.3 시점 m의 누적지출 (1항목, count대)

```
월납 = 실제 견적 입력값 또는 PMT_balloon(p, 잔존)   (할부는 일반 PMT)
누적납입(m) = 월납 × m × count
누적부대비용(m) = (보험Yr + 정비Yr) × yrs × count

누적지출(m) = (선납 + 보증금 + 현금추가 + 취득세 + 기타초기비용)×count
            + 누적납입(m) + 누적부대비용(m)
            − tradeIn − 부가세환급누적(m)
```

- tradeIn은 금융 원금이 아니라 **현금 흐름에서 차감** (v2는 원금에서 차감했으나, 다대수·자유 빌더에서는 현금 차감이 일관적 — 월납이 보상판매에 영향받지 않게 됨. 차이는 이자 상당분이며 한계로 명시)
- 부가세환급누적: rent → 월납×m×10/110×count, finlease/installment → P×10/110×count (m=0부터), oplease → 0

### 4.4 시세·출구 비용 (시점 m)

```
시세(m) = resaleOverrides에 해당 시점 있으면 그 값
        아니면 max(P × (1−감가율)^yrs, P × 최저잔존비율)     (1대당, ×count는 합산 시)

잔여개월 = max(n − m, 0)

[rent]        해지 = 누적지출 + 잔여개월×월납×count×위약금% + 점검비×count + 초과주행×count − 보증금×count
              승계 = 누적지출 + 승계수수료×count − 보증금×count    (canTransfer일 때)
              출구비용 = min(해지, 승계)

[oplease]     해지반납  = rent 해지와 동일 구조
              승계양도  = 누적지출 + 승계수수료×count − 보증금×count
              잔여채무(m) = 실제 월납 기반 잔액 (잔존 현재가치가 바닥)
              인수후매각 = 누적지출 + (max(잔여채무−할인,0)+인수취득세+기타비용)×count − 시세×count − 보증금×count
              출구비용 = 3개 중 최소

[finlease]    잔여채무(m) = 실제 월납 기반 잔액 (표준 월납이면 만기에 잔존과 일치)
              조기정산후매각 = 누적지출 + (max(잔여채무−감면,0)+기타비용)×count − 시세×count − 보증금×count
              승계 = 누적지출 + 승계수수료×count − 보증금×count (canTransfer일 때)
              출구비용 = min(조기정산후매각, 승계)
              ※ 실제 월납이 자동 산식과 다르면 그 차이를 잔여채무가 보존

[installment] 출구비용 = 누적지출 + max(잔여대출(m) − 감면, 0)×count − 시세(m)×count
```

시세 > 잔여채무이면 출구비용이 음수(이익)가 될 수 있음 — 의도된 동작 (v2 검증 포인트 6 계승).

### 4.5 세금절감 (tax.ts)

```
연비용(1대) = 방식별:
  rent/oplease:        월납×12 + 보험Yr + 정비Yr
  finlease/installment: (VAT 조정 차량가+취득세)/5 + 해당 과세기간 금융비용 + 보험Yr + 정비Yr
기간 금융비용 = max(실제월납×기간월수 − 기간 원금감소액, 0)

감가상당액(1대) = §4.2 매트릭스 행
  (rent: 월납×12×70%, oplease: ×93%, fin/inst: (VAT 조정 차량가+취득세)/5)

단계 1 — 업무사용비율:
  category=exempt + 비율 입력 → 비율 = bizUsePct / 100, 1,500만·800만 한도 없음
  category=exempt + 미입력    → 비율 = 1(100% 업무사용 가정), 위 한도 없음
  passenger + 기록부 미작성 → 비율 = min(15,000,000 / 연비용, 1)
  passenger + 기록부 작성  → 비율 = bizUsePct / 100

단계 2 — 업무사용금액 = 연비용 × 비율
단계 3 — 감가 한도 (passenger만): 초과분 = max(감가상당액 × 비율 − 8,000,000, 0)
단계 4 — 연인정액(1대) = 업무사용금액 − 초과분
단계 5 — 세금절감(m) = 12개월 이하 과세기간별 인정액 합계 × 한계세율 × count
```

- `biz = none` → 인정액·절감 0 (취득세·부가세는 그대로 부담/미환급)
- 소유형 차량 감가는 5년 정액으로 기간별 계산하며, 한도 초과액 이월은 미추적
- 대상 승용차의 필수보험 또는 법인 전용번호판 미준수는 세금절감 0으로 단순 적용

### 4.6 기회비용·최종 지표

```
초기현금(1항목) = (선납 + 보증금 + 현금추가 + 취득세 + 기타초기비용 − 초기부가세환급) × count − tradeIn
기회비용(m)    = 초기현금 × (assetReturnPct/100) × yrs        (단리)

실질순비용(m) = 출구비용(m) − 세금절감(m) + 기회비용(m)        ← 모든 비교의 최종 지표
```

### 4.7 세율 데이터 (taxData.ts)

- 개인 추정 한계세율은 기존 매핑을 유지하고, 2026 법인 추정세율은 10%/20% 사용
- 업종은 분류용이며, 부동산임대업 50% 비용인정 휴리스틱은 적용하지 않음
- 매출구간(7구간) → 추정 한계세율 매핑 (매출≠과세표준이므로 보수적 휴리스틱, 주석 명기):

  | 연매출 | ~3천만 | 3~5천만 | 5~8천만 | 8천만~1.5억 | 1.5~3억 | 3~5억 | 5억~ |
  |---|---|---|---|---|---|---|---|
  | 개인 | 6% | 15% | 15% | 24% | 35% | 38% | 40% |
  | 법인 | 10% | 10% | 10% | 10% | 10% | 20% | 20% |

  부정확성을 보완하기 위해 **한계세율 직접 입력 옵션**을 제공 (입력 시 매핑 무시)
- 취득세 기본값: 승용·9~10인승 7% / 11인승 이상 승합·화물 5% / 경차 4%
  (분류 선택 시 자동 입력, 수정 가능)
- 경형 비영업용 승용차는 2027년 말까지 취득세 75만원 감면(세액 이하이면 0원) 적용
- 업무용승용차 한도 상수: 연 1,500만 / 감가 연 800만 (대당)
- 3요건 충족 부동산임대 주업 소규모 법인: 연 500만 / 감가 연 400만

## 5. 비교 엔진 (compare.ts)

```
그리드: 시점 0, 3, 6, … max(items[].months) × 모든 항목 → 실질순비용
  · 항목 만기 이후 시점: 만기 비용으로 고정 + "종료됨" 표시 (차트는 점선)
  · m=0: 누적 0, 절감 0, 기회비용 0 — 초기현금만 반영
항목별 최적 출구 시점 = 0개월을 제외한 그리드 최소점 (참고용)
종합 최적 = common.targetMonths 동일 보유기간에서 만료되지 않은 항목 중 최소
시나리오 비교 = common.scenarios 시점마다 만료되지 않은 전 항목 비용 + 선택된 출구 방법
정규화 토글 = 총비용 | 대당 (÷count) | 월평균 (÷경과개월)
```

성능: 순수 함수 + `useMemo`. 50항목 × 17시점 < 200ms 검증 (벤치마크 테스트 1개 포함).

### 6.4 입력 검증·경고

- 잔존 현재가치가 최초 금융잔액을 넘으면 무납입 만기잔액을 상한으로 제한하고 카드에 경고
- 할부 대출금 > 차량가−선납−지원 → 자동 상한
- 음수 차단, count ≥ 1 강제
- 법인/성실신고 + passenger → "업무전용보험 가입 필수" 배지
- 항목 0개 → 빈 상태 안내 / 1개 → 단독 분석 모드 (비교 없이 시점별·세금 탭만)

### 6.5 isUsed 플래그

중고차 여부는 라벨 표시용 메타데이터. 가격에 이미 감가가 반영되어 있다고 가정하며 계산식 차이 없음 (사용자가 감가율로 조정).

## 7. 테스트 전략 (Vitest, TDD)

엔진 구현 순서: `pmt → costAt(방식별) → tax → vat/취득세 → compare`. 각 단계 테스트 먼저 작성.

| # | 케이스 | 기대값 |
|---|--------|--------|
| A | PMT 기본 | 4,000만/6%/48M → 939,401.5원/월 (v2 문서 오기 정정) |
| B | 리스 잔존 효과 | 잔존 현재가치 포함 balloon 월납, 잔존↑→월납↓ |
| C | 할부 잔여대출 | 2,800만/5.5%/48M, 24M 시점 ≈ 원금의 50~55% (v2 계승) |
| D | 1,500만 한도 | 연비용 1,800만·기록부X → 업무사용비율 = 1,500/1,800. 업무사용금액 1,500만 제한 확인 후, 감가 한도(G)와 결합한 최종 인정액을 손계산 대조 (v2 케이스를 실무형 규칙으로 갱신) |
| E | 매각 차익 | 시세 2,500만 > 잔여 1,400만 → −1,100만 반영 (v2 계승) |
| F | 금융리스 정산 | 실제 월납 기반 잔액−시세 / 표준 월납 시 만기 잔존 일치 |
| G | 800만 감가 한도 | 렌트 70%·리스 93%·정액 각각 초과분 불인정 |
| H | 다대수 한도 | 3대 → 4,500만/2,400만 확장 |
| I | 부가세 환급 | exempt+사업자: rent 매월 10/110(렌트료만), inst/fin 초기 10/110, oplease 0 |

## 8. 한계·면책 (화면 하단 + README)

1. 한계세율 근사 (누진공제 미반영)
2. 감가상각 한도 초과액 이월 미반영
3. 기회비용 단리 근사
4. 위약금·정산식은 금융사 약관별 상이 (대표 산식 사용)
5. 보상판매를 현금 차감으로 처리 (금융 원금 차감 아님 — 이자 상당분 차이)
6. 부가세 환급은 일반과세자 가정 (간이·면세사업자 미반영)
7. 업무전용보험·법인 전용번호판 요건을 사용자 선택값으로 단순 적용
8. 시세는 단순 감가커브 (모델·주행거리 미반영) — 시점별 직접입력으로 보완 가능
9. 렌트 부가세 환급은 월렌트료(금융원금 기준)에만 적용 — 선납분의 부가세는 미환급 모델 (렌트가 소폭 보수적으로 평가됨)
10. 운용리스 감가상각비 상당액은 월납액의 93% 근사

> 본 도구는 상대 비교·의사결정 보조용. 계약 전 금융사 견적 + 세무사 확인 필수.
