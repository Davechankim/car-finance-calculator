# 자동차 금융 비교 계산기

장기렌트 · 운용리스 · 금융리스 · 할부를 **자유 조합**(N항목 × 다대수)으로 비교하는 웹 계산기.
예: "금융리스 그랜저 1대 vs 운용리스 카니발 3대 vs 장기렌트 카니발 3대"

주요 기능:

- 동일한 목표 보유기간을 기준으로 총액·대당·월평균 비용 비교
- 금융리스·할부는 금융기간 종료 후에도 월납을 멈춘 상태로 보유비용·세금·시세를 계속 계산
- 실제 견적 월납을 금융·보험·자동차세·정비·서비스비로 분리해 현금흐름과 잔여채무에 각각 반영
- 과도한 할부 실납입은 조기 완납 잔액에서 멈추고, 금융 종료 후 추가 보유비용을 별도 반영
- 중도해지·승계·인수 후 매각 등 출구별 비용 자동 비교
- VAT 과세유형·증빙과 2026 승인 세법 적용기간을 명시한 세금절감 근사
- 브라우저 자동 저장, JSON 내보내기·가져오기, 초기화

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev    # http://localhost:3000
npm test       # 계산 엔진 단위 테스트 (Vitest)
npm run test:e2e  # 실제 Chromium 사용자 흐름 테스트 (Playwright)
npm run build  # 프로덕션 빌드
npm run tax:mcp:smoke  # 로컬 읽기 전용 세법 MCP 연결 확인
# LAW_OPEN_API_OC 설정 후: npm run tax:mcp:live-smoke  # 공식 조문까지 실조회
```

처음 E2E를 실행하는 환경에서는 `npx playwright install chromium`으로 테스트 브라우저를
한 번 설치합니다. 배포 전 전체 검증은 `npm run release:check`로 실행합니다.

## 구조

- `lib/engine/` — 순수 계산 엔진 (PMT·출구비용·세금·비교). **모든 공식은 단위 테스트로 검증**
- `tax-rules/approved/` — 적용일·출처가 고정된 승인 세금 규칙 / `mcp/` — 공식 법령 읽기 전용 MCP
- `lib/state/` — 기본값·리듀서·저장 데이터 검증 / `components/` — 빌더·결과 UI / `app/` — Next.js 셸
- `docs/superpowers/specs/` — 설계 문서 / `docs/verification-report.md` — 계산 검증 보고서
- `docs/tax-mcp-research.md` — 공식 세금 데이터의 안전한 MCP 연동 조사와 도입 순서
- `docs/adsense-readiness.md` — 공개 도메인·AdSense 심사 전 준비와 활성화 순서

## 계산 모델 요약

| | 장기렌트 | 운용리스 | 금융리스 | 할부 |
|---|---|---|---|---|
| 자동 월납 | 최초잔액−잔존 현재가치 | 최초잔액−잔존 현재가치 | 최초잔액−잔존 현재가치 | 대출잔액 원리금균등 |
| 취득세 | — | 인수 시 반영 | 반영 | 반영 |
| 부가세 환급* | 매월 | 없음(면세) | 초기 1회 | 초기 1회 |
| 비용처리 | 렌트료 | 리스료 | 감가+이자 | 감가+이자 |

\* 일반과세 사업자 + VAT 적격 차종 + 적격 증빙·업무 관련성을 모두 충족한 경우만.
업무용승용차 비용 한도 제외 차종과 VAT 적격 차종은 승인 스냅샷에서 서로 다른
규칙으로 관리합니다.
실질순비용 = 최적 출구비용 − 세금절감 + 기회비용. 운용리스 조기인수 정산에는
남은 금융원금과 잔존가치를 모두 반영하고, 반환형 보증금은 출구 시 환급합니다.
실제 월납액을 입력하면 현금흐름뿐 아니라 중도·만기 금융잔액에도 같은 상환표를 사용합니다.
할부 월납이 큰 경우 발생 이자를 포함한 잔액까지만 최종 납입하고 조기 완납 뒤에는
가상의 납입·이자를 더하지 않습니다. 리스의 balloon 계약 월납 규약은 유지합니다.
항목의 `기간`은 장기렌트·운용리스에서는 계약기간, 금융리스·할부에서는 금융기간입니다.
공통 목표 보유기간이 금융기간보다 길면 월 금융납입만 만기에서 중단하고 보험·정비,
감가상각·세금절감·시세는 실제 보유기간까지 이어서 계산합니다.
보유기간 전체 연간비용과 금융 종료 뒤 시작하는 추가 연간비용을 분리해 입력합니다.
취득세 과표는 VAT 포함 거래면 공급가액으로, 개인 간 중고거래처럼 VAT가 없는
가격이면 입력 전액으로 계산합니다.
경형 비영업용 승용차는 2027년 말까지 적용되는 75만원 취득세 감면을 반영합니다.
부가세 공제 가능 차량은 환급 VAT를 감가·비용 basis에서도 제외하며,
소유형 차량의 감가상각 취득가액에는 취득세를 포함합니다.
과세사업용 자산 매각에는 취득 당시 매입 VAT 공제 여부와 별개로 매출 VAT를
반영합니다. 일반과세는 예상 매각대금의 10/110, 개인사업자의 간이과세는 선택
업종의 법정 부가가치율×10%로 추정합니다. 넓은 업종 항목은 해당 법정 구분의
최대율을 사용하고, 겸영·불확실은 과소계상 방지를 위해 10/110을 보수
적용합니다. 개인자산·면세사업 전용·포괄적 사업양도 등 예외는 항목에서
해제할 수 있습니다. 운용리스 인수 후 즉시 매각에는 요건 충족 시 인수 매입 VAT
공제도 별도로 반영합니다.
실제 견적의 월납은 금융·차량대금, 보험, 자동차세, 정비, 서비스비로 나눕니다.
현금유출에는 합계를 쓰되 잔여채무와 이자는 금융·차량대금만으로 계산하고,
렌트 VAT는 보험·자동차세 포함분을 제외한 입력분에만 적용합니다.
운용리스 감가상각비 상당액은 정비비가 구분되면 총 리스료에서 보험·자동차세·
정비비를 빼고, 구분되지 않으면 보험·자동차세 차감액의 7%를 정비비로 보아
나머지 93%를 적용합니다.
월납 포함 정비비와 별도 연간 정비비는 VAT 공제요건을 충족할 때 모두 환급액과
순비용 기준에 함께 반영합니다. 렌트의 비환급 선납금도 계약기간에 배분하고
VAT 적격 거래면 선납 VAT를 초기 환급에 포함합니다.
간이·면세·겸영 또는 불확실 과세유형은 보수적으로 VAT 환급을 0원 처리합니다.

일반 업무용승용차는 무기록부 연 1,500만원·감가 연 800만원 한도를 적용합니다.
화면에서 3요건 충족을 선택한 부동산임대업 주업 소규모 법인은 각각 500만원·400만원을
적용합니다. 이 선택만으로 2026 소규모법인 세율 20%를 강제하지 않으며 제외법인·
과세표준을 확인한 사용자가 한계세율을 직접 입력할 수 있습니다.
법인 보험·전용번호판 등 필수요건 미충족은 세금절감 0원으로 처리합니다.
한도 제외 차량은 위 금액 한도를 적용하지 않되, 업무사용비율을 입력하면 해당 비율만
인정하고 미입력 시에는 100% 업무사용으로 가정합니다.
기본 `approvedOnly` 세법 적용기간은 입력한 계산 시작일부터 2026 승인 스냅샷
종료일까지만이며, 그 뒤에는 세금절감과 VAT 환급 같은 혜택을 추가하지 않습니다.
반대로 매각 VAT와 인수 취득세는 승인 종료 직후 0원이 되는 왜곡을 막기 위해
2026 규칙을 보수적으로 유지합니다. 모든 효과에 같은 규칙을 반복하는 계산은
사용자가 `assumeUnchanged` 시나리오를 선택해야 합니다.
저장 형식 v3는 `taxRuleSetId`를 함께 기록하고 현재 승인 규칙과 다른 파일을
불러오면 입력만 복구해 현재 규칙으로 다시 계산합니다. 자동 저장은 사용자가
확인할 때까지 멈춰 원본을 보존하며, v1·v2도 보존적으로 마이그레이션합니다.

## 배포

Codex Sites 프로젝트와 연결되어 있습니다. `npm run build`는 Cloudflare Workers 호환
`dist/` 번들을 만들며, `.openai/hosting.json`의 프로젝트 연결 정보로 버전을 저장·배포합니다.
GitHub PR 검증부터 비공개 운영 배포·롤백까지의 절차는
[`docs/deployment.md`](docs/deployment.md)를 따릅니다.
현재 배포는 소유자 전용이며 광고 식별자가 없으면 AdSense 스크립트·슬롯·
`ads.txt`를 활성화하지 않습니다. 게시자·두 슬롯·명시적 공개 HTTPS 주소뿐 아니라
공개 상태, Google 인증 CMP 검증, Auto ads OFF를 모두 명시해야 중앙 게이트가
열립니다. 실제 수익화에는 사이트 승인과 운영자·호스팅 정책 확인이 추가로
필요하며 세부 체크리스트는 [`docs/adsense-readiness.md`](docs/adsense-readiness.md)를
따릅니다.
