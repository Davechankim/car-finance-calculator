# 자동차 금융 비교 계산기

장기렌트 · 운용리스 · 금융리스 · 할부를 **자유 조합**(N항목 × 다대수)으로 비교하는 웹 계산기.
예: "금융리스 그랜저 1대 vs 운용리스 카니발 3대 vs 장기렌트 카니발 3대"

주요 기능:

- 동일한 목표 보유기간을 기준으로 총액·대당·월평균 비용 비교
- 실제 견적 월납액, 반환형 보증금, 기타 초기비용 반영
- 중도해지·승계·인수 후 매각 등 출구별 비용 자동 비교
- 2026 추정 세율과 업무용승용차 한도·필수요건을 반영한 세금절감 근사
- 브라우저 자동 저장, JSON 내보내기·가져오기, 초기화

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev    # http://localhost:3000
npm test       # 계산 엔진 단위 테스트 (Vitest)
npm run test:e2e  # 실제 Chromium 사용자 흐름 테스트 (Playwright)
npm run build  # 프로덕션 빌드
```

처음 E2E를 실행하는 환경에서는 `npx playwright install chromium`으로 테스트 브라우저를
한 번 설치합니다. 배포 전 전체 검증은 `npm run release:check`로 실행합니다.

## 구조

- `lib/engine/` — 순수 계산 엔진 (PMT·출구비용·세금·비교). **모든 공식은 단위 테스트로 검증**
- `lib/state/` — 기본값·리듀서·저장 데이터 검증 / `components/` — 빌더·결과 UI / `app/` — Next.js 셸
- `docs/superpowers/specs/` — 설계 문서 / `docs/verification-report.md` — 계산 검증 보고서

## 계산 모델 요약

| | 장기렌트 | 운용리스 | 금융리스 | 할부 |
|---|---|---|---|---|
| 자동 월납 | 최초잔액−잔존 현재가치 | 최초잔액−잔존 현재가치 | 최초잔액−잔존 현재가치 | 대출잔액 원리금균등 |
| 취득세 | — | 인수 시 반영 | 반영 | 반영 |
| 부가세 환급* | 매월 | 없음(면세) | 초기 1회 | 초기 1회 |
| 비용처리 | 렌트료 | 리스료 | 감가+이자 | 감가+이자 |

\* 사업자(일반과세) + 한도제외 차량(경차·9~10인승 승용·11인승↑승합·화물·영업용)만.
실질순비용 = 최적 출구비용 − 세금절감 + 기회비용. 운용리스 조기인수 정산에는
남은 금융원금과 잔존가치를 모두 반영하고, 반환형 보증금은 출구 시 환급합니다.
실제 월납액을 입력하면 현금흐름뿐 아니라 중도·만기 금융잔액에도 같은 상환표를 사용합니다.
취득세 과표는 입력한 부가세 포함 가격에서 VAT를 제외한 공급가액으로 계산합니다.
경형 비영업용 승용차는 2027년 말까지 적용되는 75만원 취득세 감면을 반영합니다.
부가세 공제 가능 차량은 환급 VAT를 감가·비용 basis에서도 제외하며,
소유형 차량의 감가상각 취득가액에는 취득세를 포함합니다.
해당 차량을 매각하는 출구에는 매출 VAT를 반영하고, 운용리스 인수 후 즉시 매각에는
인수 매입 VAT 공제도 함께 반영합니다.

일반 업무용승용차는 무기록부 연 1,500만원·감가 연 800만원 한도를 적용합니다.
화면에서 3요건 충족을 선택한 부동산임대업 주업 소규모 법인은 각각 500만원·400만원을
적용합니다. 법인 보험·전용번호판 등 필수요건 미충족은 세금절감 0원으로 처리합니다.
한도 제외 차량은 위 금액 한도를 적용하지 않되, 업무사용비율을 입력하면 해당 비율만
인정하고 미입력 시에는 100% 업무사용으로 가정합니다.

## 배포

Codex Sites 프로젝트와 연결되어 있습니다. `npm run build`는 Cloudflare Workers 호환
`dist/` 번들을 만들며, `.openai/hosting.json`의 프로젝트 연결 정보로 버전을 저장·배포합니다.
GitHub PR 검증부터 비공개 운영 배포·롤백까지의 절차는
[`docs/deployment.md`](docs/deployment.md)를 따릅니다.
